# 红魔互传常开 · 1.1

为 NX789J 的红魔互传设置自动关闭时间，或保持常开。

## 使用

1. 覆盖安装 `RedMagicShareKeepOn-1.1.apk`。
2. 首次使用时，在 LSPosed / Vector 启用本模块，作用域只选择「红魔互传」。安装或升级后重启手机。
3. 打开本应用，设置两个开关和自动关闭时间。

| 设置 | 行为 |
| --- | --- |
| 启用模块 | 使用所选关闭时间；关闭模块后恢复原厂 10 分钟策略 |
| 打开红魔互传 | 直接开启或关闭系统互传 |
| 自动关闭时间 | 1分钟、5分钟、10分钟、30分钟、60分钟、常开 |

升级默认保留「常开」。修改时间时，如果互传已开启，会从修改时重新计时；互传未开启时不会自动开启。进程重新启动后按原厂保存的开始时间恢复剩余时长。到期调用原厂关闭流程，继续保留正在传输时的处理。

底部「版本与更新」使用与磁贴自定义相同的卡片、按钮样式和文字。可查看 GitHub 更新和项目主页；无浏览器时可复制链接。

## 适配

- 机型：NX789J，应用最低 Android 14。
- 互传包名：`com.zte.cn.zteshare`。
- 互传版本：`16.0.000.000.2607131724`。
- DEX SHA-256：`a65f3ebc49931f25e3d04da3e3c94743f996384b341db0a93bc02e45a8b1d840`。

代码指纹不匹配时不修改互传逻辑。版本名称 `1.1`，内部版本号 `110`，官方安装包与 1.0 使用相同签名，可覆盖安装。

## 编译

Linux x86_64、Python 3.10+、Java 17+（含 keytool）：

```bash
python3 build.py
```

脚本下载固定版本的官方构建工具并校验 SHA-256；使用前请自行阅读并遵守各依赖许可。本地构建默认生成开发签名，与已发布安装包的签名不同。发行构建可指定保留的私有密钥：

```bash
export RMSK_KEYSTORE_PASSWORD='your-password'
python3 build.py --keystore /path/to/private-release.p12 --alias your-alias
```

Xposed API 仅参与编译，不随 APK 打包。原系统 APK、反编译系统代码、私有签名和本地工具缓存均不包含在源码包中。
